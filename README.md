# Titulky na Reels

Webová aplikace na automatické české titulky k videím pro Instagram Reels. Funguje v počítači i v mobilu a běží celá v prohlížeči: přepis řeči (Whisper přes transformers.js), úprava textu, 47 stylů titulků a export MP4 s vypálenými titulky nebo SRT. Videa se nikam neodesílají a nic se neplatí.

Návod: [NAVOD.md](NAVOD.md)

Spuštění lokálně: `python server.py` a otevři http://localhost:8765
